Currency Converter:
A simple currency converter website made with HTML, CSS and JavaScript.

Features:
- Convert currencies
- Select different currencies
- Swap currencies
- Shows country flags
- Automatically fetches the exchange rate when the page loads
- Uses an API to get exchange rates
- FlagsAPI — Currency/country flag images
- Simple and responsive design

Technologies:
- HTML
- CSS
- JavaScript
- ExchangeRate API

How to Use
1. Enter the amount.
2. Select the currencies.
3. Click the convert button.
4. The converted amount will be displayed.

This project helped me practice JavaScript, API integration, DOM manipulation and basic error handling.
